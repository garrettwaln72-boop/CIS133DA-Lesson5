The Differences of Generic Font Famillies

The different font families are stylistic choices to put into a website in order to express vibe of the website. You could use a serif font, to convey a more elegant or traditinal site. You could use a sans-serif font to project the site as more minimalist or modern. Regardless of your choice the importance of families really lies in their use as a declaration for a fallback if the users computer lacks the font. If it's unavailable then you can set a font family declaration in order to maintian the style of your site should the user's computer not have the necesary font.

How to Express Color

There are multiple ways to express color in CSS. First is the RGB color, which utilizes the values of red green and blue in seperate channels each color represented by a number between 0-255 in order to generate a specific color. Next is the hexadecimal color code. It's similar to the RGB color in that it represents the same 3 color channels in a 2 digit code represented by 0-9 and a-f. If you're going for simplicity however, you can simply name the color you with to use, though this method may be limited by the browser the user has.
